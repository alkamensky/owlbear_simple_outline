# Token Outline for Owlbear Rodeo

Простой аддон для **Owlbear Rodeo**, который помогает сделать токены заметнее на насыщенных картах.

## Возможности

- обводка токенов;
- настройка цвета обводки;
- настройка толщины обводки в пикселях;
- режим минимальной тени*;
- режим «обводка + тень*»;
- применение к выделенным токенам или ко всем Character-токенам на сцене;
- удаление эффекта с выбранных токенов.

*- на данный момент тени работают некорректно, затемняя сам объект тоже

## Установка

В Owlbear Rodeo откройте:

**Extensions → Add a custom extension**

И вставьте ссылку:

```text
https://simple-outline.altraboxel.workers.dev/manifest.json
```

После этого добавьте расширение и включите его.

## Использование

1. Выделите один или несколько токенов на сцене.
2. Откройте **Token Outline**.
3. Выберите режим:
   - Outline;
   - Shadow;
   - Outline + Shadow.
4. Для обводки задайте цвет и толщину.
5. Нажмите кнопку применения эффекта.

Аддон особенно полезен для прозрачных top-down токенов, которые сливаются с детализированной картой.

## Примечание

Расширение создано для использования с Owlbear Rodeo и распространяется как небольшой пользовательский инструмент.
